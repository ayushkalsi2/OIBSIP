# 🌡️ Temperature Converter A clean, responsive web app that converts temperatures between **Celsius**, **Fahrenheit**, and **Kelvin** in real time — built as part of the OIBSIP Web Development Internship (Level 1, Task 3). 🔗 **Live Demo:** _(https://drive.google.com/file/d/113qMB774DBh2zRQ_rkui6XQoHbYoJDCJ/view?usp=drive_link)_ ## ✨ Features - **Instant conversion** — results update live as you type, no page reload - **All three units at once** — see Celsius, Fahrenheit, and Kelvin side by side - **Quick reference chips** — tap common temperatures (boiling point, body temp, absolute zero, etc.) to auto-fill and convert - **Formula hints** — displays the exact formula used for the current conversion - **Input validation** — friendly error message for invalid or empty input - **Keyboard support** — press Enter to convert - **Fully responsive** — works smoothly on mobile and desktop - **Dark, modern UI** — built with the Space Grotesk font and a custom dark theme ## 🛠️ Built With - HTML5 - CSS3 (custom properties / CSS variables, Grid & Flexbox) - Vanilla JavaScript (no frameworks or libraries) - [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) via Google Fonts ## 📁 Project Structure ``` temperature-converter/ │ ├── index.html # Complete app (HTML + CSS + JS in one file) └── README.md # Project documentation ``` ## 🚀 Getting Started No build tools or dependencies required. 1. Clone or download this repository ```bash git clone https://github.com//temperature-converter.git ``` 2. Open `index.html` in any modern web browser That's it — the app runs entirely client-side. ## 🧮 Conversion Formulas | From → To | Formula | |---|---| | Celsius → Fahrenheit | `(°C × 9/5) + 32` | | Celsius → Kelvin | `°C + 273.15` | | Fahrenheit → Celsius | `(°F − 32) × 5/9` | | Fahrenheit → Kelvin | `(°F − 32) × 5/9 + 273.15` | | Kelvin → Celsius | `K − 273.15` | | Kelvin → Fahrenheit | `(K − 273.15) × 9/5 + 32` | ## 📸 Preview _(Add a screenshot of the app here once deployed, e.g. `![Preview](screenshot.png)`)_ ## 🙋 Author **Ayush** 📧 ayushkalsi15@gmail.com ## 📄 License This project is open source and free to use for learning purposes.
